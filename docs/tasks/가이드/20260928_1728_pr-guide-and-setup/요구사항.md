# 요구사항: 완전 복원 가이드·지식 정리 및 프로젝트 구성

**TL;DR**: 사용자가 WAV → FFT → IFFT → WAV 완전 복원을 Python으로 직접 구현할 수 있도록, Claude는 코드 없이 ① Python 프로젝트·실행 환경 구성, ② Sullivan 1.5 FFT 경로 사양(근거 포함), ③ 필요한 지식·공식 정리, ④ 단계별 구현 가이드라인을 만든다. 완료 기준은 네 산출물의 존재와 근거 표기, 그리고 문서에 과제 구현 코드가 없는 것이다.

## 1. 사용자 요청

> "wav파일에서 fft 후 ifft하는 Perfect Reconstruction을 하여 다시 wav로 복원하는 프로젝트를 할꺼야. 조건은 아래와 같아.
> 1. 1.5에서 fft까지의 경로를 모사한 동작. 단 agc는 제외. 윈도우나 fft설정 512 오버랩 방식까지 동일
> 2. 손코딩으로 할꺼니까 내가 직접 요청하지 않는 이상 코드를 주지마.
> 3. pyton으로 구현 할껀데, 내가 문법이나 프로젝트 구성하는 법을 잘 모르니까, 거기만 도와줘.
> 4. fft,ifft 라이브러리는 쓰지 않고 직접 구현.
> 5. 필요한 지식이나 공식같은 것도 정리.
> 6. 가이드 라인 정도는 만들어줘."

### 1.1 모호점과 해소 결과

질문은 두 차례로 나누어 선택지로 물었고, 아래는 사용자 답변이다.

| 항목 | 질문 | 사용자 답변 |
|---|---|---|
| 질문_1 | 프로젝트 위치와 형태 | `projects/` 신규 + 로컬 git. 폴더명은 기본안 `fft-perfect-reconstruction` |
| 질문_2 | 수치 표현 수준 | 부동소수점 + 수식 Hanning |
| 질문_3 | 허용 라이브러리 범위 | "fft,ifft를 제외하고는 제한 없음" |
| 질문_4 | 입력 WAV 조건 | "우선은 1번(16 kHz, 모노, 16bit PCM 고정)으로 구현하고, 그 다음 과제로 다른 주파수에서도 사용가능하도록 변경. 단, 주파수가 달라도 16샘플, 512 fft는 최대한 유지" |
| 질문_5 | 1.5 믹서의 입력 스케일(`>> 5`) 포함 여부 | 제외 |
| 질문_6 | 조건부 2탭 이동평균 LPF 경로 포함 여부 | 제외, 기본 경로만 |
| 질문_7 | 문서에 Python 문법 예시 포함 여부 | 일반 문법 예시만 포함 |
| 질문_8 | Claude가 만드는 파일 범위 | 폴더와 설정 파일만. `.py`는 사용자가 생성 |

> [!NOTE]
> **해석**: 요청의 "1.5"는 Sullivan 1.5 외부기 펌웨어(`projects/sulivan1.5/td24-18-s-ext-as`)로 읽었다. 질문_2와 질문_4의 문구에 1.5 펌웨어에서 확인한 값(윈도우 표 위치, 16 kHz, 프레임 16샘플)을 적어 제시했고 사용자가 그 전제로 답했다.

## 2. 목표

- 목표_1: 사용자가 Python 프로젝트를 구성하고 실행할 수 있는 환경(폴더, 가상환경, 의존성 목록)을 갖춘다
- 목표_2: 모사 대상인 1.5 FFT 경로의 사양을 근거와 함께 한 문서로 정리한다
- 목표_3: 구현에 필요한 지식과 공식을 정리한다
- 목표_4: 코드 없이 단계별로 따라갈 수 있는 구현 가이드라인을 만든다
- 목표_5: 구현 자체는 사용자가 한다. Claude는 이후 문법·구성 질문에 답한다

## 3. 수용 기준 (Definition of Done)

### 3.1 기능·산출물

- [ ] 수용기준_1: `projects/fft-perfect-reconstruction/`에 표준 골격(`CLAUDE.md`, `src/`, `tests/`, `docs/`)과 로컬 git 저장소가 있다
- [ ] 수용기준_2: Python 실행 환경이 구성되어 있다 — 가상환경, 의존성 목록 파일, `.gitignore`. 구성 절차와 실행 방법이 문서로 남아 있다
- [ ] 수용기준_3: 1.5 FFT 경로 사양 문서가 있고, 표의 각 항목에 `파일:라인` 근거가 붙어 있다. 확인하지 못한 항목은 `(미확인)`으로 표시한다
- [ ] 수용기준_4: 지식·공식 정리 문서가 있고 다음을 포함한다 — DFT와 역 DFT 정의, radix-2 FFT 알고리즘, Hanning 윈도우, 프레임과 중첩, 중첩 합산과 정규화, WAV PCM 형식, 복원 검증 지표. 각 공식에 출처 또는 유도 과정이 표기되어 있다
- [ ] 수용기준_5: 구현 가이드라인 문서가 있고, 단계마다 목표·입력과 출력·확인 방법·필요한 문법 항목이 있다
- [ ] 수용기준_6: 모든 산출 문서에 FFT·IFFT·윈도우·프레임·복원의 구현 코드가 없다. 문법 예시는 과제와 무관한 일반 예시만 있다
- [ ] 수용기준_7: `.py` 파일을 Claude가 만들지 않았다
