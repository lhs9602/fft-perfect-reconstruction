## 2. 분석 핵심 — 1.5 FFT 경로에서 확인한 사실

경로는 모두 `projects/sulivan1.5/td24-18-s-ext-as/` 기준이다.

| 항목 | 값 | 근거 |
|---|---|---|
| 샘플링 | 16 kHz | `Sullivan1_5__CFX/systemControl/main.c:88` |
| 프레임(한 번에 새로 들어오는 샘플) | 16샘플 | `Sullivan1_5__CFX/signalProcessing/definitionsForAlgorithm.h:56` |
| FFT 크기 | 512 | 같은 파일 `:100`, `Sullivan1_5__HEAR/microcode.hct:18` |
| FFT 입력 버퍼 | 512칸 FIFO, 블록 16 | `Sullivan1_5__HEAR/microcode.hct:14`, `:143` |
| 프레임마다 하는 일 | 16샘플을 FFT FIFO에 넣고 512점 윈도우 FFT 실행 | `main.c:232`, `:236`, `signalProcessing/FrequencyAnalysis.c:33-44` |
| 투입 순서 | 버퍼 인덱스 15 → 0 순으로 기록. 입력 FIFO는 인덱스 0이 최신이라고 주석에 적혀 있다 | `FrequencyAnalysis.c:35-43`, `systemControl/audioMixer.c:32` |
| 버퍼 초기 상태 | 0으로 지움 | `lib_cfx/lib_audio_in.c:129`, `:144` |
| 윈도우 | Hanning, 512개, 앞 256개 표 + 뒤 256개는 앞을 뒤집어 복사 | `Sullivan1_5__CM3/Gen1_5/FS/ci_fft.c:594-618` |
| 변환 모듈 | `Win_DFT_R_Forward`, K = 512 | `Sullivan1_5__HEAR/microcode.hct:174-184` |

유도·검산한 값 (명령 출력 근거, 내부 검증 스크립트):

- 중첩: 512 − 16 = 496샘플, 중첩률 96.875%. 샘플 하나는 32개 프레임에 걸친다 (512 ÷ 16)
- 1.5 윈도우 표는 **대칭형 Hanning** `0.5·(1 − cos(2πn/511))`에 (2²³ − 1)을 곱해 **절삭**한 값과 256개 전부 일치한다. 주기형(분모 512)과는 일치하지 않는다
- 대칭형 Hanning을 16샘플 간격으로 겹쳐 더한 합은 상수가 아니다 — 위치에 따라 15.96870 ~ 15.96883 (주기형이면 정확히 16)
- 복원 확인: 위치별 윈도우 합으로 나누면 최대 오차 2.2e-11, 반올림 후 16bit 입력과 전 샘플 일치
- 속도: 순수 Python 기준 프레임당 약 1.6 ms (FFT + IFFT 포함). 1초 분량 1,031프레임에 1.69초

미확인:

- FFT FIFO 안에서 512샘플이 메모리상 어떤 시간 순서로 놓이는지 (미확인). 윈도우가 좌우 대칭이어서 크기 스펙트럼은 순서와 무관하다는 점은 지식 문서에서 수식으로 보인다

## 3. 설계 결정

| 결정 | 내용 | 이유 |
|---|---|---|
| 결정_1 윈도우 수식 | 대칭형(분모 511) Hanning을 수식으로 생성 | 사용자가 수식 생성을 골랐고, 1.5 표가 대칭형과 일치한다 |
| 결정_2 복원 방식 | 분석 윈도우만 곱하고, IFFT 결과를 겹쳐 더한 뒤 **위치별 윈도우 합(16개 값)** 으로 나눈다 | 대칭형은 합이 상수가 아니어서 상수로 나누면 오차가 남는다. 프레임 단독으로 윈도우를 나누는 방식은 양 끝 값이 0이라 쓸 수 없다 |
| 결정_3 경계 처리 | 버퍼를 0으로 시작하고, 입력이 끝난 뒤 0으로 된 프레임을 31개 더 넣는다 | 1.5의 초기 상태와 같고, 모든 샘플이 32개 프레임에 걸쳐 정규화 값이 같아진다 |
| 결정_4 구현 순서 | 정의식 그대로의 단순 DFT를 먼저 만들고 FFT를 그 결과와 비교한다 | FFT 라이브러리를 쓰지 않으므로 비교 기준을 직접 만든다 |
| 결정_5 시험 대조 | `numpy.fft`는 시험 대조에도 쓰지 않는다 | 사용자 답 "fft,ifft를 제외하고는 제한 없음" |
| 결정_6 문서 위치 | `docs/가이드/` 신설, 프로젝트 `CLAUDE.md` Layout에 등재 | 루트 표준의 `docs/`는 `지침/`과 `tasks/`뿐이어서 위치 승인이 필요하다 |
| 결정_7 의존성 | `numpy`, `matplotlib`, `pytest`. WAV 입출력은 표준 라이브러리 `wave` | 현재 PC에 Python 3.11.0, numpy 2.4.6, matplotlib 3.11.2 설치 확인. 가상환경에 새로 설치한다 |
