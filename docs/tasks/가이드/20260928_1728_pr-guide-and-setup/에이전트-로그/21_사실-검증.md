## 4. 지적 요약

판정과 교체 문장은 반환한 findings에 있다. 주요 항목은 다음과 같다.

1. 그림_4와 §5 결론: (코사인 합, 사인 합)을 복소수로 그리면 위상 −90° 입력의 각도가 +90°다. §6.1에서 사인 합에 −를 붙이는 까닭이 §5에 없다.
2. §6.3 N÷2: bin 0과 N/2는 진폭 × N이고 켤레 짝도 없다. 직접 계산으로 DC 진폭 2 → X[0] = 16, 나이퀴스트 진폭 2 → X[4] = 16.
3. §4 직교성: 7주기 코사인과 1주기 기준 코사인의 내적이 4(N = 8). "주파수가 다른 사인파끼리 0"은 k와 N−k에서 틀린다.
4. §4 "내적 0 = 없다"는 §5(사인 입력, 내적 0)와 모순.
5. §2, §5 "크기가 진폭"은 X[k]에서 진폭 × N÷2다. Smith의 phasor는 크기가 진폭이다.
6. §6.4 bin 0: 기준 코사인은 1이지만 기준 사인은 0이다.
7. §11 "위치"의 정의가 없다.
8. 나머지는 조건 서술과 문장 다듬기다.
