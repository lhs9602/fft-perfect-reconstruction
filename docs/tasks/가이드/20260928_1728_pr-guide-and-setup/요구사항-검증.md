## 3. 근거 검증 (단계별 게이트)

### 3.1 재진술

사용자가 원하는 것을 다시 쓰면 다음과 같다.

- 만들려는 것은 소리 파일을 주파수 영역으로 바꿨다가 되돌려 **원본과 같은 소리 파일**을 얻는 프로그램이다
- 주파수 영역으로 바꾸는 방식은 새로 설계하지 않고 **회사 1.5 펌웨어가 실제로 쓰는 조건**(한 번에 들어오는 샘플 수, 변환 길이 512, 윈도우, 겹치는 방식)을 그대로 따른다. 펌웨어에 있는 자동 이득 조절은 뺀다
- 프로그램은 **사용자가 직접 타이핑해서** 만든다. Claude가 완성 코드를 건네면 목적이 사라진다
- 사용자는 Python 문법과 프로젝트를 꾸리는 법에 익숙하지 않아 **그 부분의 도움**이 필요하다
- 변환과 역변환은 **기성 함수를 부르지 않고** 알고리즘을 직접 짠다
- 구현에 앞서 **알아야 할 이론과 공식**, 그리고 **어떤 순서로 만들지 안내**를 문서로 받고 싶다
