# 계획: 완전 복원 가이드·지식 정리 및 프로젝트 구성

**TL;DR**: 승인 뒤 ① Python 환경(가상환경, 의존성 목록, `.gitignore`, `data/`)을 구성하고 ② `docs/가이드/`에 문서 5편(프로젝트 구성, 1.5 경로 사양, 지식과 공식, 구현 가이드라인, 문법 길잡이)을 쓴다. 문서에는 과제 구현 코드를 넣지 않고 `.py` 파일도 만들지 않는다. 문서는 끝나는 대로 대화에 올리고, 커밋은 메시지 승인 뒤에만 한다.

## 1. 전체 시퀀스

| 순서 | 단계 | 산출물 |
|---|---|---|
| 1 | Step 1 환경 구성 | `.gitignore`, `requirements.txt`, `.venv/`, `data/input/`, `data/output/` |
| 2 | Step 2 1.5 경로 사양 문서 | `docs/가이드/02_1.5 FFT 경로 사양.md` |
| 3 | Step 3 지식과 공식 문서 | `docs/가이드/03_지식과 공식.md` |
| 4 | Step 4 구현 가이드라인과 문법 길잡이 | `docs/가이드/04_구현 가이드라인.md`, `docs/가이드/05_Python 문법 길잡이.md` |
| 5 | Step 5 프로젝트 구성 문서와 인덱스 | `docs/가이드/01_프로젝트 구성과 실행 환경.md`, `docs/가이드/README.md`, `CLAUDE.md` Layout 갱신 |
| 6 | Step 6 구현 검증 | `구현-검증.md`, `이력 및 결과.md` 갱신 |

02 → 03 → 04 순서인 이유: 04의 각 단계가 02의 수치와 03의 공식 번호를 가리킨다. 01을 뒤에 쓰는 이유: Step 1에서 실제로 구성한 결과(설치된 버전, 명령 출력)를 옮겨 적는다.

## 2. 단계별 상세

### Step 1: 환경 구성

**작업**:
- `python -m venv .venv`로 가상환경 생성, 가상환경 안에서 `numpy`, `matplotlib`, `pytest` 설치
- 설치된 버전을 확인해 `requirements.txt`에 버전을 고정해 적는다
- `.gitignore` 작성 — `.venv/`, `__pycache__/`, `.pytest_cache/`, `data/output/` 안의 WAV
- `data/input/`, `data/output/` 생성 (`.gitkeep`)

**영향 파일**: 신규 4개 + 폴더 3개
**검증**: 가상환경의 Python으로 `numpy`, `matplotlib` import와 `pytest --version` 실행, 출력 기록
**commit 메시지**: `Chore: Python 가상환경 구성 파일과 데이터 폴더 추가`

### Step 2: 1.5 경로 사양 문서

**작업**:
- [분석.md](분석.md) §1.2, §1.3의 표를 사용자가 읽는 문서로 옮긴다 — 모사하는 것, 제외하는 것, 미확인인 것을 나눈다
- 1.5 경로와 Python 파이프라인의 단계 대응표를 넣는다
- 복원 쪽은 1.5에 없는 단계임을 밝힌다 (분석 제약_1)

**영향 파일**: 신규 1개
**검증**: 모든 `파일:라인`을 다시 열어 대조
**commit 메시지**: Step 5와 함께 `Docs: 완전 복원 가이드 문서 5편 추가`

### Step 3: 지식과 공식 문서

**작업**: 아래 목차로 쓴다. 공식마다 번호(`공식_1` …)를 붙여 04에서 가리킬 수 있게 한다.

| 절 | 내용 |
|---|---|
| 1 | 표기와 기호 |
| 2 | 복소수, 오일러 공식 |
| 3 | DFT와 역 DFT 정의, 1/N의 위치 |
| 4 | DFT의 성질 — 실수 입력의 켤레 대칭, bin 번호와 주파수, 에너지 관계 |
| 5 | radix-2 FFT — 짝수·홀수 분할, 버터플라이, 비트 반전, 연산량 |
| 6 | FFT로 IFFT 구하기 |
| 7 | Hanning 윈도우 — 대칭형과 주기형, 1.5 표와의 관계 |
| 8 | 프레임, 이동 간격, 중첩 |
| 9 | 중첩 합산과 완전 복원 — 유도, 위치별 윈도우 합, 다른 방법(합성 윈도우) |
| 10 | 경계 처리와 지연 |
| 11 | WAV와 PCM 16bit |
| 12 | 부동소수점 오차와 검증 지표(최대 오차, SNR) |
| 13 | 참고 자료 |

- 외부 출처(교재, 논문, 공식 문서)는 **원문을 열어 확인한 것만** 문서명과 절 제목으로 인용한다
- 확인하지 못한 공식은 유도 과정을 본문에 적고 "유도"라고 밝힌다. 수치는 첨부 검산 출력을 근거로 든다

**영향 파일**: 신규 1개
**검증**: 공식마다 출처 또는 유도 표기가 있는지 전수 확인. 수치가 첨부 출력과 같은지 대조
**commit 메시지**: Step 5와 함께

### Step 4: 구현 가이드라인과 문법 길잡이

**작업**:
- 04 — 단계_0 ~ 단계_10과 후속 과제. 단계마다 목표, 입력과 출력, 할 일(말로 설명), 확인 방법과 기대값, 가리키는 공식 번호, 필요한 문법 항목
- 05 — 문법 항목별 설명과 **과제와 무관한 일반 예시**. 04의 각 단계가 05의 항목을 가리킨다

가이드라인 단계:

| 단계 | 만드는 것 | 확인 방법 |
|---|---|---|
| 단계_0 | 환경 확인 | 가상환경에서 Python과 pytest 실행 |
| 단계_1 | WAV 읽기와 쓰기 | 헤더 값 확인, 읽은 것을 그대로 써서 원본과 비교 |
| 단계_2 | 정의식 DFT와 역 DFT | 임펄스, 직류, 정수 bin 사인파의 기대값과 비교 |
| 단계_3 | radix-2 FFT | 단계_2 결과와 비교 |
| 단계_4 | IFFT | FFT 후 IFFT 왕복 오차 |
| 단계_5 | Hanning 윈도우 | 양 끝 0, 좌우 대칭, 1.5 표 값과 대조 |
| 단계_6 | 프레임 공급(512 버퍼, 16샘플씩) | 프레임 번호와 버퍼 내용의 관계 |
| 단계_7 | 분석(윈도우 곱, FFT) | 사인파 입력의 피크 위치 |
| 단계_8 | 합성(IFFT, 중첩 합산, 정규화) | 윈도우 합 16개 값, 복원 오차 |
| 단계_9 | WAV 저장 | 반올림과 범위 |
| 단계_10 | 복원 검증 | 최대 오차, SNR, 샘플 일치 |
| 후속 | 다른 샘플레이트 지원 | 프레임 16, FFT 512 유지 |

문법 예시의 기준:

| 구분 | 넣는다 | 넣지 않는다 |
|---|---|---|
| 소재 | 장바구니 합계, 온도 목록, 이름표처럼 과제와 무관한 것 | 샘플, 윈도우, 스펙트럼, 프레임을 다루는 것 |
| 길이 | 한두 줄에서 서너 줄 | 함수 하나를 완성하는 분량 |
| 내용 | 문법 하나의 쓰임 | 과제 단계의 풀이 절차 |

**영향 파일**: 신규 2개
**검증**: 코드 블록을 전부 찾아 위 기준에 맞는지 하나씩 확인
**commit 메시지**: Step 5와 함께

- `.py` 파일 0개 확인 (`.venv` 제외)
- 02 문서의 `파일:라인` 재대조
- 경로 변경·이동은 이번 작업에 없다. 구 경로 리터럴 검사는 해당 없음
