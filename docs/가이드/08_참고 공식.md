## 1. 스펙트럼의 성질

**참고_1** 실수 입력의 켤레 대칭

- **무엇인가** — 입력이 실수이면 스펙트럼의 **뒤쪽 절반은 앞쪽 절반의 켤레**라는 성질이다. 그래서 새로운 정보는 bin 0 ~ 256에만 있다
- **어디에 쓰는가** — 단계_3에서 FFT가 맞는지 확인할 때($X[512-k]$와 $X[k]$의 켤레가 같은가). 단계_7에서 크기가 큰 bin을 0 ~ 256에서만 찾는 까닭. 선택 단계 "절반만 보관"

$$X[N-k] = X[k]^*, \qquad k = 1, \dots, N-1$$

| 기호 | 뜻 | 이 프로젝트의 값 |
|---|---|---|
| $X[k]$ | $k$번 bin의 스펙트럼 값 | |
| $X[N-k]$ | 뒤에서 $k$번째 bin의 값 | $k = 32$이면 $X[480]$ |
| $X[k]^*$ | $X[k]$의 켤레. 허수부의 부호만 바꾼 것 | |
| $N$ | 변환의 길이 | 512 |

**도출** (유도)

1. [03](03_지식과%20공식.md) 공식_2의 $k$ 자리에 $N - k$를 넣는다: $X[N-k] = \sum_n x[n]\, e^{-j2\pi (N-k)n/N}$
2. 지수를 둘로 나눈다: $e^{-j2\pi (N-k)n/N} = e^{-j2\pi n}\, e^{+j2\pi kn/N}$
3. $n$은 정수이므로 $e^{-j2\pi n} = 1$([03](03_지식과%20공식.md) 공식_1 아래의 "한 바퀴 돌면 제자리"). 남는 것: $X[N-k] = \sum_n x[n]\, e^{+j2\pi kn/N}$
4. $x[n]$이 실수이면 $x[n]^* = x[n]$이다. 그러므로 각 항 $x[n]\,e^{+j2\pi kn/N}$은 $x[n]\,e^{-j2\pi kn/N}$의 켤레다
5. 켤레들의 합은 합의 켤레다: $X[N-k] = \Bigl(\sum_n x[n]\,e^{-j2\pi kn/N}\Bigr)^* = X[k]^*$

3에서 본 것처럼 $N - k$번 bin의 지수는 $+j2\pi kn/N$, 곧 **거꾸로 $k$바퀴** 도는 사인파다. 그래서 bin $N - k$는 "음의 주파수" 자리다.

손계산: $x = [1, 2, 3, 4, 0, 0, 0, 0]$에서 $X[1] = -0.4142 - 7.2426j$, $X[7] = -0.4142 + 7.2426j$(도출_7). [03](03_지식과%20공식.md) 공식_2의 $N = 4$ 손계산에서 bin 3이 bin 1과 같은 값 2였던 것도 이 성질이다(실수 2의 켤레는 2).

- 근거: **출처** — 같은 책 "Symmetry" ("the spectrum of every real signal is Hermitian", 실수부는 짝함수, 허수부는 홀함수). 원문의 $X(-k)$를 $X[N-k]$로 옮긴 것은 **유도**다 — [03](03_지식과%20공식.md) 공식_2에서 $k$ 자리에 $k+N$을 넣어도 값이 같다
- **검산**: 분석 검산 검산_2에서 최대 위반 1.8e-14
- 따라서 서로 독립인 bin은 $k = 0 \dots N/2$, 즉 **257개**다. $X[0]$과 $X[256]$은 자기 자신의 켤레와 같으므로 실수다(유도). 기대값 검산 기대값_7에서 두 bin의 허수부가 0으로 나왔다

**참고_2** bin 번호와 주파수

- **무엇인가** — $k$번 bin이 **몇 Hz**를 나타내는지로 바꾸는 식이다
- **어디에 쓰는가** — 단계_7의 확인(1000 Hz 사인파가 bin 32에 나타나는가), 결과를 읽을 때, 시험용 사인파의 주파수를 고를 때(참고_10)

$$f_k = k \cdot \frac{f_s}{N}, \qquad k = 0, \dots, N/2$$

| 기호 | 뜻 | 이 프로젝트의 값 |
|---|---|---|
| $f_k$ | $k$번 bin이 나타내는 주파수 (Hz) | |
| $k$ | 주파수 bin의 번호 | 0 ~ 256 |
| $f_s$ | 샘플링 주파수 | 16000 Hz |
| $N$ | 변환의 길이 | 512 |
| $f_s / N$ | bin 하나의 간격 | 31.25 Hz |

**도출** (유도)

1. $k$번 bin의 사인파 $e^{j2\pi kn/N}$은 $N$샘플 동안 $k$바퀴 돈다([03](03_지식과%20공식.md) 공식_2의 도출 1)
2. $N$샘플이 걸리는 시간은 $N / f_s$초다. 512샘플이면 $512 \div 16000 = 0.032$초
3. 주파수는 1초에 도는 바퀴 수이므로 $k \div (N/f_s) = k \cdot f_s/N$
4. 예: bin 32는 0.032초에 32바퀴 → 1초에 1000바퀴 → 1000 Hz

$k$가 $N/2$보다 큰 bin은 참고_1의 "음의 주파수" 자리여서 실수 입력에서는 새 정보가 없다. 그래서 $k = 0 \dots N/2$까지만 적었다. 가장 높은 $k = 256$이 $f_s / 2 = 8000$ Hz다.

- 근거: **유도** — "DFT Definition"의 $\omega_k = k \cdot 2\pi/(NT)$를 $2\pi$로 나누고 $f_s = 1/T$를 넣어도 같은 식이 나온다

| $k$ | 주파수 |
|---|---|
| 1 | 31.25 Hz |
| 32 | 1000 Hz |
| 256 | 8000 Hz |

**참고_3** 에너지 관계 (파스발)

- **무엇인가** — 샘플 쪽에서 잰 에너지(제곱의 합)와 스펙트럼 쪽에서 잰 에너지가 같다는 관계다. [03](03_지식과%20공식.md) 공식_3의 규약 때문에 오른쪽에 $1/N$이 붙는다
- **어디에 쓰는가** — 단계_3의 확인. 아무 입력이나 넣어 양쪽을 계산해 같으면 FFT가 맞을 가능성이 높다

$$\sum_{n=0}^{N-1} \lvert x[n]\rvert^2 = \frac{1}{N}\sum_{k=0}^{N-1} \lvert X[k]\rvert^2$$

| 기호 | 뜻 |
|---|---|
| $\lvert x[n]\rvert^2$ | 입력 값의 크기를 제곱한 것 |
| $\lvert X[k]\rvert^2$ | 스펙트럼 값의 크기를 제곱한 것. 복소수의 크기는 [03](03_지식과%20공식.md) 공식_1 아래의 표에 있다 |
| 왼쪽 | 입력 512개의 제곱을 모두 더한 값 |
| 오른쪽 | 스펙트럼 512개의 제곱을 모두 더하고 $N$(512)으로 나눈 값 |

**도출** (유도)

1. 복소수 크기의 제곱은 자기 켤레와의 곱이다: $\lvert X[k]\rvert^2 = X[k]\, X[k]^*$ ($z = a + jb$이면 $z z^* = a^2 + b^2$)
2. [03](03_지식과%20공식.md) 공식_2를 넣는다. 켤레 쪽은 번호를 $n'$으로 적는다: $X[k]\,X[k]^* = \sum_n x[n]\,e^{-j2\pi kn/N} \sum_{n'} x[n']^*\,e^{+j2\pi kn'/N}$
3. $k$에 대해 모두 더하고 합의 순서를 바꾼다: $\sum_k \lvert X[k]\rvert^2 = \sum_n \sum_{n'} x[n]\,x[n']^* \sum_k e^{-j2\pi k(n-n')/N}$
4. 안쪽 합은 직교성([03](03_지식과%20공식.md) §3)에 따라 $n = n'$이면 $N$, 아니면 0이다(지수의 부호가 반대여도 켤레일 뿐이어서 결과는 같다)
5. 남는 것: $\sum_k \lvert X[k]\rvert^2 = N \sum_n x[n]\,x[n]^* = N \sum_n \lvert x[n]\rvert^2$. 양변을 $N$으로 나누면 참고_3

손계산: $x = [1, 2, 3, 4, 0, 0, 0, 0]$에서 왼쪽은 $1 + 4 + 9 + 16 = 30$, 오른쪽도 30이다(도출_7).

- 근거: **출처** — 같은 책 "Rayleigh Energy Theorem (Parseval's Theorem)"
- **검산**: 기대값 검산 기대값_7에서 양쪽의 상대 차이 1.6e-16
- FFT를 짠 뒤 임의의 입력으로 양쪽을 계산해 보면 구현을 확인할 수 있다

## 2. 윈도우

### 2.1 주기형

**참고_4** 주기형 Hanning (정의)

분모를 $N$으로 둔 형태를 주기형이라고 한다(정의). 이 프로젝트의 기본 구현에는 쓰지 않고, 선택 단계 "주기형 윈도우"에서 대칭형과 비교할 때만 쓴다. 도출은 [03](03_지식과%20공식.md) 공식_9와 같고 분모만 $N$이다.

$$w_p[i] = 0.5 - 0.5\cos\!\left(\frac{2\pi i}{N}\right), \qquad i = 0, 1, \dots, N-1$$

| 기호 | 뜻 | 이 프로젝트의 값 |
|---|---|---|
| $w_p[i]$ | 주기형 윈도우의 $i$번째 값. 아래 글자 $p$는 주기형(periodic)이라는 표시다 | |
| $N$ | 분모. 대칭형([03](03_지식과%20공식.md) 공식_9)과 다른 곳은 여기 하나다 | 512 |
| $i$ | 윈도우 안에서의 번호 | 0 ~ 511 |

SciPy 문서 `scipy.signal.windows.hann`은 두 형태를 `sym` 인자로 고르게 하고, 대칭형은 필터 설계용, 주기형은 스펙트럼 분석용이라고 적는다(출처). 이 프로젝트는 1.5를 따라 **대칭형**을 쓴다. 주기형은 [03](03_지식과%20공식.md) §9.3에서 비교 대상으로만 나온다.

### 2.2 프레임 안의 순서를 뒤집으면

**참고_5** 순서를 뒤집은 프레임의 스펙트럼 (유도)

- **무엇인가** — 프레임 안의 샘플을 앞뒤로 뒤집어 넣으면 스펙트럼이 어떻게 달라지는지다
- **어디에 쓰는가** — 코드에는 쓰지 않는다. 1.5 버퍼 안의 샘플 순서를 확인하지 못했는데([02](02_1.5%20FFT%20경로%20사양.md) §6), 순서가 뒤집혀 있어도 **크기 스펙트럼은 같다**는 근거다

프레임의 512샘플을 앞뒤로 뒤집어 넣었을 때의 스펙트럼을 $X_r[k]$라고 하면 (유도)

$$X_r[k] = e^{\,j 2\pi k/N}\; X[k]^*, \qquad \lvert X_r[k]\rvert = \lvert X[k]\rvert$$

| 기호 | 뜻 |
|---|---|
| $X[k]$ | 프레임을 원래 순서로 넣었을 때의 스펙트럼 |
| $X_r[k]$ | 프레임의 512샘플을 앞뒤로 뒤집어 넣었을 때의 스펙트럼. 아래 글자 $r$은 뒤집었다(reversed)는 표시다 |
| $X[k]^*$ | $X[k]$의 켤레 |
| $e^{\,j 2\pi k/N}$ | 크기가 1인 복소수. 곱해도 크기는 바뀌지 않고 각도만 바뀐다 |
| $\lvert \cdot \rvert$ | 복소수의 크기 |

**도출** (유도)

1. 뒤집어 넣은 입력은 $i$번 칸에 $b[N-1-i]$가 들어 있다. 윈도우를 곱하면 $b[N-1-i]\,w[i]$
2. 윈도우는 좌우 대칭이므로 $w[i] = w[N-1-i]$([03](03_지식과%20공식.md) 공식_9의 도출 4). 그래서 $b[N-1-i]\,w[N-1-i]$
3. 합의 번호를 $i' = N - 1 - i$로 바꾼다: $X_r[k] = \sum_{i'} b[i']\,w[i']\,e^{-j2\pi k(N-1-i')/N}$
4. 지수를 나눈다: $e^{-j2\pi k(N-1-i')/N} = e^{-j2\pi k}\,e^{+j2\pi k/N}\,e^{+j2\pi ki'/N}$. $e^{-j2\pi k} = 1$(정수 $k$바퀴)
5. 남는 것: $X_r[k] = e^{j2\pi k/N} \sum_{i'} b[i']\,w[i']\,e^{+j2\pi ki'/N}$. 버퍼와 윈도우가 실수이므로 합은 $X[k]$의 켤레다(참고_1의 도출 4, 5와 같은 까닭)
6. 크기가 1인 복소수를 곱해도, 켤레를 취해도 크기는 그대로다: $\lvert X_r[k]\rvert = \lvert X[k]\rvert$

**검산**: 크기의 최대 차이 7.1e-15, 복소수 값 자체의 최대 차이 41.4(분석 검산 검산_5). 크기는 같고 위상은 다르다.

## 3. 복원의 다른 방법 — 합성 윈도우

IFFT 결과에 윈도우를 **한 번 더** 곱한 뒤 겹쳐 더하는 방법도 있다. *Spectral Audio Signal Processing*의 "Weighted Overlap Add"는 IFFT 뒤, 겹쳐 더하기 전에 두 번째 윈도우를 곱하는 방식을 설명한다(출처). 이때의 복원식은 아래와 같다.

**참고_6** 합성 윈도우를 쓸 때 (유도)

- **무엇인가** — IFFT 결과에 윈도우를 한 번 더 곱한 뒤 겹쳐 더하는 **다른 복원 방법**의 식이다
- **어디에 쓰는가** — 선택 단계 "합성 윈도우". 기본 구현에는 쓰지 않는다

$$\hat{x}[n] = \frac{\sum_m y_m[i]\, w[i]}{W_2[n \bmod R]}, \qquad W_2[r] = \sum_{q=0}^{N/R-1} w[r + qR]^2$$

| 기호 | 뜻 |
|---|---|
| $y_m[i]\, w[i]$ | IFFT 결과에 윈도우를 한 번 더 곱한 값 |
| $\sum_m$ | 샘플 $n$이 걸치는 프레임 32개에 대해 더한다. $i$는 프레임마다 그 샘플이 놓인 버퍼 위치다 |
| $W_2[r]$ | 위치 $r$에서의 **윈도우 제곱**의 합. 아래 글자 2는 제곱이라는 표시다 |
| $w[r + qR]^2$ | 윈도우 값을 제곱한 것 |
| 나머지 | [03](03_지식과%20공식.md) 공식_14, [03](03_지식과%20공식.md) 공식_15와 같다 |

**도출** (유도): [03](03_지식과%20공식.md) §9.2의 도출 1 ~ 3과 같다. 4에서 각 프레임이 더하는 값이 $y_m[i]\,w[i] = x[n]\,w[i]\,w[i] = x[n]\,w[i]^2$이 되므로([03](03_지식과%20공식.md) 공식_13), 32개를 더하면 $x[n]$에 윈도우 **제곱** 32개의 합 $W_2[r]$이 곱해진다. 양변을 $W_2$로 나누면 참고_6이다.

| 항목 | 값 | 근거 |
|---|---|---|
| $W_2[r]$의 범위 | 11.976562310991 ~ 11.976562667733 | 분석 검산 검산_6 |
| 최대 절대 오차 | 2.55e-11 | 같음 |

이 프로젝트의 가이드라인은 [03](03_지식과%20공식.md) 공식_15를 쓴다. 참고_6은 나중에 스펙트럼을 고치는 실험을 할 때 참고한다.

## 4. 지연

**참고_7** 지연 (유도)

- **무엇인가** — 소리가 들어오는 대로 처리한다면 복원한 소리가 **얼마나 늦게 나오는지**다
- **어디에 쓰는가** — 코드에는 쓰지 않는다. 파일을 처리할 때는 자리를 맞춰 저장하므로 출력 파일에 지연이 없다. 1.5처럼 실시간으로 처리하는 장치라면 이만큼 늦는다

$$D = N - R$$

| 기호 | 뜻 | 이 프로젝트의 값 |
|---|---|---|
| $D$ | 지연. 출력이 입력보다 늦는 샘플의 수 | 496샘플 |
| $N$ | 버퍼의 길이 | 512 |
| $R$ | 프레임 크기 | 16 |
| $D / f_s$ | 시간으로 바꾼 지연 | 496 ÷ 16000 = 31 ms |

**도출** (유도)

1. 샘플 $n$은 프레임 $\lfloor n/R \rfloor$에 들어가고 프레임 $\lfloor n/R \rfloor + N/R - 1$까지 걸친다([03](03_지식과%20공식.md) §7). 이 마지막 프레임까지 더해야 복원값이 완성된다
2. 두 프레임의 차이는 $N/R - 1 = 31$프레임이고, 한 프레임이 $R = 16$샘플이므로 $31 \times 16 = N - R = 496$샘플
3. 16 kHz에서 $496 \div 16000 = 0.031$초 = 31 ms

샘플 하나하나로 보면, 완성되는 순간까지 들어온 가장 새 샘플과의 차이는 묶음 안의 위치에 따라 496 ~ 511샘플이다(샘플 15는 496, 샘플 0은 511. 기대값 검산 기대값_20의 도출_10). 위의 496은 프레임 단위로 센 값이다.

## 5. 오차와 검증 지표

**참고_8** 최대 절대 오차 (정의)

- **무엇인가** — 복원한 샘플 가운데 **가장 많이 틀린 것이 얼마나 틀렸는지**다
- **어디에 쓰는가** — 구현하지 않는다. 04 단계_8의 확인 표에 나오는 "최대 차이"가 이 값이다. 복원 검증(단계_10)은 `tv.compare_wav`가 한다

$$e_{\max} = \max_{0 \le n < L}\; \bigl\lvert \hat{x}[n] - x[n] \bigr\rvert$$

| 기호 | 뜻 |
|---|---|
| $e_{\max}$ | 최대 절대 오차. 가장 많이 틀린 샘플이 얼마나 틀렸는가 |
| $\hat{x}[n]$ | 복원한 샘플 |
| $x[n]$ | 원래의 입력 샘플 |
| $\lvert \cdot \rvert$ | 절댓값. 차이의 부호를 떼어 낸다 |
| $\max_{0 \le n < L}$ | 모든 샘플($n$ = 0 ~ $L-1$) 가운데 가장 큰 값 |

**판정 기준이 0.5인 까닭** (유도): 원래 샘플 $x[n]$은 정수다. 반올림 전의 값이 $\lvert \hat{x}[n] - x[n]\rvert < 0.5$이면 $\hat{x}[n]$에서 가장 가까운 정수는 $x[n]$이다. 그래서 $e_{\max} < 0.5$이면 반올림한 뒤 모든 샘플이 원래 값과 같다.

**참고_9** 신호 대 잡음비 (정의)

- **무엇인가** — 신호가 오차보다 **몇 배 큰지**를 dB로 나타낸 값이다. 오차가 작을수록 커진다
- **어디에 쓰는가** — 구현하지 않는다. 복원이 얼마나 정확한지를 한 수로 나타낼 때의 참고

$$\mathrm{SNR} = 10\log_{10}\!\left(\frac{\sum_n x[n]^2}{\sum_n \bigl(\hat{x}[n] - x[n]\bigr)^2}\right)\ \text{dB}$$

| 기호 | 뜻 |
|---|---|
| $\mathrm{SNR}$ | 신호 대 잡음비. 신호가 오차보다 몇 배 큰지를 dB로 나타낸 값. 클수록 복원이 정확하다 |
| $\sum_n x[n]^2$ | 분자. 원래 샘플의 제곱을 모두 더한 것 (신호의 에너지) |
| $\sum_n (\hat{x}[n] - x[n])^2$ | 분모. 복원값과 원래 값의 차이를 제곱해 모두 더한 것 (오차의 에너지) |
| $10\log_{10}$ | 비율을 dB로 바꾼다. Python에서는 `10 * math.log10(...)` |

**도출** (정의와 그 뜻)

1. 신호의 세기를 제곱의 합(에너지)으로 잰다. 오차도 같은 방법으로 잰다
2. 둘의 비율을 dB로 적는다. 에너지(제곱)의 비율은 $10\log_{10}$을 하면 dB가 된다 — 비율이 10배면 10 dB, 100배면 20 dB
3. 예: 진폭 10000인 사인파의 제곱 평균은 $10000^2 / 2 = 5 \times 10^7$이다($\sin^2$의 평균이 1/2 — [03](03_지식과%20공식.md) 공식_9의 도출 5의 반각 공식에서 코사인의 평균이 0이므로). 오차의 제곱 평균이 1(샘플마다 한 눈금씩 틀림)이면 SNR은 77.0 dB, $10^{-22}$(오차가 1e-11 수준)이면 297.0 dB다(도출_12)

오차가 전부 0이면 분모가 0이 된다. 이 경우는 따로 처리해야 한다(예: "오차 없음"으로 표시).

**판정 기준** (정의)

| 비교 대상 | 기준 | 참고값 |
|---|---|---|
| 반올림 **전**의 복원값과 입력 | $e_{\max}$가 0.5보다 충분히 작다 | 2.18e-11 (분석 검산 검산_4) |
| 반올림 **후** 저장한 WAV와 입력 WAV | 전 샘플이 같다 | 전 샘플 일치 (같음) |

**부동소수점 비교**

실수 계산에는 아주 작은 오차가 남는다. 두 실수가 같은지를 `==`로 확인하면 안 되고 차이가 허용 범위 안인지를 본다. Python에서 `0.1 + 0.2 == 0.3`은 거짓이고 `math.isclose(0.1 + 0.2, 0.3)`은 참이다([첨부_이력_문법 예시 실행 출력.txt](../tasks/가이드/20260928_1728_pr-guide-and-setup/첨부_이력_문법%20예시%20실행%20출력.txt)). 문법은 [05_Python 문법 길잡이.md](05_Python%20문법%20길잡이.md) §13에 있다.

## 6. 시험용 신호

**참고_10** 사인파의 샘플 (정의)

- **무엇인가** — 주파수가 하나뿐인 소리(사인파)의 **샘플 값**을 계산하는 식이다
- **어디에 쓰는가** — 구현하지 않는다. 시험용 사인파 `data/input/sine_1k.wav`는 ffmpeg로 만든다([01](01_프로젝트%20구성과%20실행%20환경.md) §7.3). 그 명령의 식이 이 식이고, 문서의 기대값이 모두 이 신호 기준이다

$$x[n] = \mathrm{round}\!\left(A \sin\!\left(\frac{2\pi f n}{f_s}\right)\right), \qquad n = 0, 1, \dots, L-1$$

| 기호 | 뜻 | 시험용 신호의 값 |
|---|---|---|
| $A$ | 진폭. 16bit 정수의 크기 | 10000 |
| $f$ | 주파수 (Hz). $f_s/2$보다 낮아야 한다 | 1000 |
| $f_s$ | 샘플링 주파수 | 16000 |
| $L$ | 샘플 수 = 길이(초) × $f_s$ | 16000 (1초) |

**도출** (유도)

1. 주파수 $f$의 사인파는 1초에 $f$바퀴 돈다. $t$초 동안 $f t$바퀴, 각도로 $2\pi f t$다. 그래서 값은 $\sin(2\pi f t)$
2. 크기를 $A$로 키운다: $A\sin(2\pi f t)$
3. $n$번째 샘플의 시각은 $t = n / f_s$초다(1초에 $f_s$개를 적으므로)
4. 넣으면 $A\sin(2\pi f n / f_s)$. WAV에는 정수만 적으므로 반올림한다([07](07_WAV%20파일.md) 변환_1) — 참고_10

예: $f = 1000$, $f_s = 16000$, $n = 1$이면 각도는 $2\pi/16$, 곧 16분의 1바퀴(22.5°)다. $10000 \times \sin 22.5° = 3826.8$ → 3827.

| 주파수 | 한 주기의 샘플 수 ($f_s \div f$) | bin 번호 ($f \div 31.25$, 참고_2) | 앞 5개 (진폭 10000) |
|---|---|---|---|
| 500 Hz | 32 | 16 | 0, 1951, 3827, 5556, 7071 |
| 1000 Hz | 16 | 32 | 0, 3827, 7071, 9239, 10000 |
| 2000 Hz | 8 | 64 | 0, 7071, 10000, 7071, 0 |
| 4000 Hz | 4 | 128 | 0, 10000, 0, −10000, 0 |
| 440 Hz | 36.36 | 14.08 | 0, 1719, 3387, 4955, 6374 |

근거: 기대값 검산 기대값_19. `data/input/sine_1k.wav`의 16,000샘플은 이 식(1000 Hz, 진폭 10000)의 값과 모두 같다(2026-09-29 확인).

| 알아 둘 것 | 내용 |
|---|---|
| bin의 중심에 맞는 주파수 | 31.25 Hz의 배수(500, 1000, 2000 Hz 등)는 bin 번호가 정수다. 440 Hz처럼 bin 사이에 놓이는 주파수는 스펙트럼에서 이웃한 여러 bin에 나뉘어 나타난다. 윈도우 없이 512점을 변환했을 때 1000 Hz는 bin 32 하나만 크고(2,560,026, 그다음은 38), 440 Hz는 bin 14, 15, 13에 나뉘었다(2,526,261 / 226,913 / 180,543) |
| 윈도우를 곱하면 | bin의 중심에 맞는 주파수도 양옆 bin으로 퍼진다 ([04](04_구현%20가이드라인.md) 단계_7의 bin 31, bin 33) |
| 파일로 만드는 법 | ffmpeg — [01](01_프로젝트%20구성과%20실행%20환경.md) §7.3 |
