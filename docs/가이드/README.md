# 가이드 (문서 인덱스)

**TL;DR**: WAV → FFT → IFFT → WAV 완전 복원을 Python으로 직접 구현하기 위한 문서 11편이다. 01로 환경을 확인하고, 02로 무엇을 따라 하는지 본 뒤, 04의 단계를 따라가며 03(구현에 필요한 공식), 07(WAV 파일), 05(문법)를 찾아본다. DFT가 식만으로 어려우면 09의 그림을, FFT는 10의 그림을 본다. 왜 구하는지와 결과가 무엇을 의미하는지는 11을 본다. 만든 함수는 06으로 확인한다. 구현 코드는 없다.
